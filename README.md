## Jak utrzymujemy repozytorium

- Bieżąca gałąź publikacji: **`main`**.
- Kolejne próbki dodajemy do opisanego katalogu i uzupełniamy ten indeks.
- Zachowujemy istniejące ścieżki, żeby linki przekazane odbiorcom nadal działały.
- To publiczne portfolio. Nie dodajemy `.env`, kluczy, cookies, danych klientów, prywatnej korespondencji ani zrzutów bazy.
- Backend i konfiguracja prywatnych usług nie są częścią tego portfolio.
